# snakey

A Snake game built with Phaser 3 and TypeScript, bundled with Vite.

## Controls

- **Arrow keys** — move the snake (Up / Down / Left / Right)
- **Space** or **click** — restart after game over

## Requirements

- Node.js 20+

## Getting started

```bash
npm install        # install dependencies
npm run dev        # start the dev server with HMR
npm run build      # type-check and build for production
npm run preview    # serve the production build locally
```

## Project layout

| File | Purpose |
|---|---|
| `src/main.ts` | Phaser game bootstrap and configuration |
| `src/scenes/GameScene.ts` | Game logic and rendering |
